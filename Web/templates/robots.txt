# 页面全站允许抓取；只屏蔽「接口 + 登录/注册」三类无搜索价值的地址（见下）。
# 别顺手再往上加 Disallow：搜索引擎要能抓到 CSS/JS/图片才能正确渲染页面，
# 而本站的关键资源都在这站内（Web/static），字体图标来自 CDN、由 CDN 自己的 robots.txt 管。
User-agent: *

# 只屏蔽计数接口：它只接受 POST、不是页面，抓它纯属浪费抓取预算。
# （robots.txt 只约束爬虫，浏览器里的 fetch 不受影响，播放计数照常上报。）
Disallow: /api/

# 登录 / 注册：永久 noindex、没有任何搜索价值，却会被 "喜欢" 按钮带出
# /login.html?next=/song/xxx.html 这样的大量变体地址（Google 站长后台会看到一堆
# 「被 noindex 排除」，还白占抓取预算）。这两个页面本来就是给用户点的，拦爬虫不影响使用。
Disallow: /login.html
Disallow: /register.html

# ============ 以下几个路径是**故意不屏蔽**的，改之前先读完这段 ============
#
# /so/<关键词>.html（搜索页）
#   搜索页是刻意做成长尾落地页的：有结果时输出 index, follow（见 search.html 的 robots 块）。
#   一旦这里 Disallow，爬虫就读不到页面上的 noindex 标签 —— 空结果页反而会以
#   "无描述"的形式长期留在索引里。官方建议：想不收录就用 noindex，别用 robots.txt 拦。
#
# /download/<sid>/mp3.html
#   下载功能已关闭，现在一律返回 404。必须让它继续返回 404，爬虫才会把
#   已经被收录的下载页从索引里清掉；Disallow 会让爬虫看不到 404，那些页面会一直挂着。
#
# 未收录但未被屏蔽的还有：带参数的列表地址（会 301 收敛）、/singer/<sid>/<页码>.html
# 这类不在 sitemap 里的深分页 —— 让爬虫自己顺着链接走就行，不必在这里逐一列举。

# 站点地图：绝对地址用**规范域名**（settings.SITE_URL，与 canonical 同源），
# 避免 www / 裸域各生成一份、让搜索引擎当成两套站点。
Sitemap: {{ SITE_BASE }}/sitemap.xml
